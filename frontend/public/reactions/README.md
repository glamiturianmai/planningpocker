`emoji-ru.json` — русский каталог из `emoji-picker-element-data@1.8.0`,
файл `ru/emojibase/data.json`. Лицензия: `emoji-data-LICENSE.txt`.

Каталог хранится в приложении, чтобы поиск эмодзи не зависел от внешнего CDN.
Для обновления скопируйте файл из установленного пакета и проверьте,
что серверная библиотека `emoji` распознаёт все значения поля `emoji`.
